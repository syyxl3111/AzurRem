## 一、结论先行：后端已经通了，一行都不用改

原以为必须改 AzurPilot 源码加 REST 接口。实测发现**项目自带一个 MCP 服务，已经挂在 25548 端口上**（`module/webui/app.py:380,395`），而且是完整可用的。

本机实测（已跑通完整 JSON-RPC 往返，非推测）：

```
GET  http://192.168.1.100:25548/mcp/sse      → event: endpoint
                                                 data: /mcp/mcp/messages?session_id=<32位hex>
POST http://192.168.1.100:25548/mcp/mcp/messages?session_id=<id>
```

> ⚠️ 注意路径是 **`/mcp/mcp/messages`**（双 `mcp`）——因为 `SseServerTransport("/mcp/messages")` 被挂载在 `/mcp` 下。客户端必须使用 SSE 首帧返回的 `data` 字段，**不能硬编码**。

### App 内的 MCP 客户端

OkHttp（`okhttp-sse`）实现，逻辑很薄，**不需要常驻长连接**：

```
每 30s 一轮：
  1. GET /mcp/sse           → 解析首帧 data 拿 session_id
  2. POST initialize
  3. POST notifications/initialized
  4. POST tools/call × N    → 同一 session 内连续调用（资源/状态/日志/队列）
  5. 关流，30s 后重来
```

天然抗断线（每轮都是新 session），正好贴合 30s 轮询。

### 3.1 设计令牌

```

                  圆角  20dp（卡片）/ 28dp（底部 Tab Bar、状态条）
```

### 5.2 资源行规范

| 类型 | 行高 | 结构 |
|---|---|---|
| 带上限（石油、物资） | ~76dp | 点 + 名称 + 数值（右对齐）／ 进度条 ／ 上限 + 相对时间 |
| 无上限（其余 10 项） | ~56dp | 点 + 名称 + 数值 ／ 相对时间 |
| 行动力 | ~56dp | 数值后跟 `(3080)` = Total，不画进度条 |
| 活动PT | ~56dp | 若配置了 `PtLimit` 则显示 ` / N` |

**进度条规则（按你的要求）：**

```
填充比例 = min(Value / Limit, 1.0)     ← 绝不超出，满格封顶
显示数值 = Value                       ← 真实值，可能 > Limit
```

石油/物资**过了上限仍能继续存**，所以会出现 `12,400 / 11,200` 这种状态。此时：

- 数值照实显示 `12,400`
- 进度条**满格不溢出**
- 上限文字变为 `已溢出 · 上限 11,200`（用警示色 `#FF9F0A` 轻量标注，不弹窗不告警）

`ActionPoint` 用 `Total`（当前 + 未开箱）而非 `Limit`，不画进度条，直接显示 `80 (3080)`。

### 5.3 启动 / 停止 FAB（右下角）

这是主页唯一的主操作，做成**可拖动的悬浮按钮**：

| 状态 | 外观 | 点击行为 |
|---|---|---|
| **已停止** | 三角形 ▶（`#0A84FF` 实心），亚克力底座 | `start_instance` |
| **运行中** | 正方形 ■ **外面环绕一圈旋转的弧**（旋转 = 心跳/活动指示） | `stop_instance` |
| **异常**（state 3） | 三角形 + 琥珀色描边 | `start_instance` |
| **更新中**（state 4） | 旋转弧 + 禁用态（降透明度） | 无 |

**拖动交互**（对齐 Android 惯例，类似聊天气泡）：

- 长按 200ms 进入拖拽，跟手
- 松手后**吸附到最近的左/右边缘**（垂直位置保留，限制在安全区内）
- 位置持久化，下次启动恢复
- 拖拽中轻微放大（1.0 → 1.06）+ 阴影加深，提示"可移动"
- **不遮挡资源行**：拖动中列表照常滚动，FAB 始终浮在最上层
- 危险操作保护：停止时若 `state == 1`，先弹亚克力确认条（"确认停止 alas？"），避免误触

> 之所以要吸附边缘：全自由摆放会让它落在列表文字上，既挡信息又不好点。吸附后它只占用边缘条带，和 iOS 的 AssistiveTouch 一个思路。

## 附：关键技术风险

| 风险 | 评估 | 应对 |
|---|---|---|
